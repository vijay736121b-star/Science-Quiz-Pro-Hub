# 🧪 Science Quiz Pro hub

**Learn Science. Test Your Knowledge.**

Science Quiz Pro is a native Android educational quiz application designed to make science learning engaging, simple, and interactive.

## ✨ Features

- 🧠 51 curated science questions
- 🔬 Biology, Chemistry, Physics, Astronomy, and Earth Science
- ⏱️ Configurable question timer
- 🔀 Randomized questions and answer options
- ✅ Instant feedback for correct and incorrect answers
- 📚 Scientific explanations after each question
- 📊 Score, percentage, grade, and performance summary
- 🔎 Review all questions and answers
- 💾 Local result history
- 📱 Clean and responsive Android UI
- 🔒 Privacy-focused and offline-friendly
- 🚫 No account or login required

## 🎯 Purpose

Science Quiz Pro is created to help students and science enthusiasts test their knowledge, practice important concepts, and learn through interactive quizzes.

## 🛠️ Technology

- Kotlin
- Android SDK
- Jetpack Compose
- Material Design
- Local data storage
- Gradle
